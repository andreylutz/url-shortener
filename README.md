# Консольный сервис сокращения ссылок

Сервис сокращения URL с лимитами переходов, сроком действия ссылок
и управлением по UUID владельца. Открытие исходного адреса - через Java Desktop.

## Требования

JDK 25 и Maven 3.9.11+. Команды `java` и `mvn` должны быть доступны в терминале.
При первой сборке нужен доступ к Maven Central для загрузки зависимостей.

## Сборка

Из корня проекта:

```bash
mvn clean verify
```

Команда запускает тесты, проверяет форматирование и создаёт `target/url-shortener.jar`.

## Запуск

```bash
java -jar target/url-shortener.jar
java -jar target/url-shortener.jar --config config/application.properties
```

Без `--config` используется `config/application.properties`.
Параметр `--config <путь>` выбирает другой файл настроек целиком.
Файл читается в UTF-8; все настройки обязательны. Относительные пути отсчитываются
от рабочего каталога. При ошибке настроек приложение выводит причину и завершает работу с кодом 1.

## Параметры конфигурации

- `link.ttl.seconds` - срок жизни ссылки в секундах.
- `link.default-limit` - лимит переходов по умолчанию.
- `cleanup.interval.seconds` - интервал фоновой очистки в секундах.
- `link.prefix` - префикс коротких ссылок.
- `link.code.length` - длина короткого кода.
- `storage.path` - путь к файлу данных.
