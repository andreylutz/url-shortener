# Консольный сервис сокращения ссылок

Создаёт короткие ссылки с лимитом переходов и сроком действия, открывает исходный URL
через Java Desktop. Управление ссылками - по UUID владельца. Данные сохраняются в JSON.

## Требования

JDK 25, Maven 3.9.11+ и доступ к Maven Central при первой сборке.

## Сборка и запуск

Из корня проекта:

```bash
mvn clean verify
java -jar target/url-shortener.jar
```

Сборка запускает тесты и Spotless, создаёт JAR с зависимостями.
GitHub Actions выполняет эту проверку на `push` и `pull_request`.
Для другого файла настроек добавьте к запуску `--config <путь>`.

## Использование

В консоли приложения:

```text
create https://example.org 5
list
open <полученная короткая ссылка>
```

Сохраните выданный UUID. Для второго пользователя: `user new`, затем `create https://example.org 5`.
Вернуться к первому: `user <UUID>`.
Короткие ссылки открываются командой `open`; HTTP-сервера в приложении нет.

- `create <URL> [limit]` - создать ссылку с указанным или стандартным лимитом.
- `user new` / `user <UUID>` - начать нового или выбрать существующего пользователя.
- `list` / `show <link>` - список и параметры своих ссылок.
- `open <link>` - открыть исходный URL в браузере.
- `set-limit <link> <limit>` / `set-url <link> <URL>` - изменить свою ссылку.
- `delete <link>` - удалить свою ссылку.
- `notifications` - прочитать уведомления.
- `help` / `exit` - справка с примерами и выход; конец ввода также завершает приложение.

`<link>` - полученная короткая ссылка. URL - абсолютный `http` или `https`, пробелы - `%20`.

## Настройки

Файл `config/application.properties` в UTF-8; все параметры обязательны.
Относительные пути отсчитываются от рабочего каталога.
Для существующих данных сохраняйте прежние `link.prefix` и `link.code.length`.

- `link.ttl.seconds` - срок жизни ссылки в секундах.
- `link.default-limit` - лимит переходов по умолчанию.
- `cleanup.interval.seconds` - интервал фоновой очистки в секундах.
- `link.prefix` - префикс коротких ссылок.
- `link.code.length` - длина короткого кода.
- `storage.path` - путь к файлу данных.

## Правила работы

Каждое сокращение создаёт новую ссылку. Лимит N разрешает N успешных вызовов открытия браузера;
загрузка страницы не проверяется, ошибка вызова не расходует переход.
Редактировать и удалять ссылку может только владелец. Новый лимит должен превышать счётчик;
счётчик, владелец и TTL при редактировании сохраняются.
Системный TTL блокирует ссылку при `now >= expiresAt`. Очистка удаляет её при запуске
или очередном проходе с интервалом `cleanup.interval.seconds`.
Уведомление создаётся при достижении лимита или первом обнаружении истечения TTL;
показывается владельцу один раз при следующей команде или выборе UUID, сохраняется после удаления ссылки.

JSON записывается через временный файл и атомарную замену. Отсутствующий файл означает пустое
хранилище; повреждение или ошибка записи останавливают работу. Один файл - один экземпляр приложения.
Знающий UUID может выбрать владельца без пароля - полноценной авторизации нет.

## Архитектура

`src/shortener`: `core` - модели, сервисы и порты; `infrastructure` - настройки, JSON, браузер
и планировщик; `ui/console` - консоль. `Main` собирает зависимости. `test/shortener` - unit-
и интеграционные тесты с подменой браузера и управляемым `Clock`.
